SubTopo-Geo — projet Android mis à jour

L’interface intégrée à l’application se trouve dans app/src/main/assets/index.html. Elle inclut les exports CSV, DXF, KML et KMZ pour les points, traces, parcelles et mesures.

Les fichiers Kotlin et la configuration Android du projet d’origine sont conservés. L’interface HTML mise à jour conserve les appels au pont Android pour le GPS et l’enregistrement des fichiers.

Cette archive contient le projet source Android, pas un APK compilé. Ouvrir le dossier subtopo-geo dans Android Studio pour le compiler.
